# Hswele Ehin Tse Portfolio 2

A personal portfolio for UI/UX and product designer Hswele Ehin Tse, built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

Run npm install, then npm run dev. Open http://localhost:3000.

## Sections

- Selected product work
- Design process
- About, skills, and experience
- Contact links and downloadable CV
